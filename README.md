# Logon34

Workplace logon-script UI (`Logon34.exe`; VersionCompanyName Computer Sciences Corporation / Tusk Technologies) that maps drives via WNet APIs, resolves site/logon server from the environment and subnet, and reports progress while the logon script runs (Logon 33/34 evolution). Open `Logon.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe
